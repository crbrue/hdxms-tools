# Roadmap

## v1.1 validation

- Validate dual SI tables against the original SI-summary notebook on representative projects.
- Tune peptide-QC thresholds against curated high- and low-quality datasets.
- Add schema-version validation for manifests and analysis reports.
- Add optional HTML/PDF rendering from `analysis_report.yaml` without changing the machine-readable source.

## Non-goals for v1.1

- Automatic peptide exclusion based on QC score.
- Reformatting the canonical SI summary table.
- Replacing raw HX Examiner exports.
